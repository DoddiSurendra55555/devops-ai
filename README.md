## 🚀 How to Install (Early Access)

Since this extension is in active development, you can install it directly from the GitHub Release:

1. Go to the [Releases page](../../releases) on this repository.
2. Download the `devops-ai-1.0.0.vsix` file.
3. Open VS Code.
4. Go to the **Extensions** tab (`Ctrl+Shift+X`).
5. Click the three dots (`...`) in the top right corner of the Extensions panel.
6. Select **"Install from VSIX..."** and choose the file you just downloaded.
7. Open the Command Palette (`Ctrl+Shift+P`), type `DevOps AI: Set Gemini API Key`, and start scanning!
